# README.md

## معرفی

این مخزن (repository) برای توسعه یک **Agent** طراحی شده است که متن‌های تجربه کاربران را دریافت کرده و موارد زیر را در آن‌ها بررسی می‌کند:

* **تشخیص توهین**: شناسایی وجود یا عدم وجود الفاظ و جملات توهین‌آمیز در متن.
* **اطلاعات تماس**: شناسایی شماره تلفن، ایمیل یا هر نوع اطلاعات تماس دیگر.
* **احتمال نام شخص**: بررسی احتمال وجود نام افراد در داخل متن.

در حال حاضر، تنها **prompt** (متن فرمان) مربوط به این Agent در مخزن قرار داده شده است.
